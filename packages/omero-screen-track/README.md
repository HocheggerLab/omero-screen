# omero-screen-track

GUI-free cell-tracking logic for the OMERO-Screen platform: lineage repair on
PIP-FUCCI timelapse plates, the Track Review edit log and its replay, debris,
cell fates and phases, and the review queue. The napari Track Review widget and
the `cellview` track commands are front ends to it.
