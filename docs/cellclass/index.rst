CellClass — ML Cell Classifier
================================

**cellclass** is the machine-learning training pipeline for the OmeroScreen ecosystem.
It trains lightweight convolutional neural networks to classify single-cell crops generated by the
:doc:`Training Widget </omero-screen-napari/training_widget>` and deploys the resulting
`TorchScript <https://pytorch.org/docs/stable/jit.html>`_ models back into the
:doc:`omero-screen pipeline </pipeline>` for automated inference.

The package follows a four-step workflow:

1. **Create dataset** — normalise and package ``.npy`` crop files into a single ``.npz`` archive.
2. **Write a training batch file** — one run per line with model and hyperparameter flags.
3. **Train** — run all jobs locally or on a SLURM cluster; results log to Weights & Biases.
4. **Extract model** — export the best checkpoint to a TorchScript ``.pt`` + ``.json`` sidecar for inference.
